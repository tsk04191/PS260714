# PS260714

Unity 프로젝트에서 사용하는 C# 스크립트를 공유하고 버전 관리하기 위한
스크립트 전용 저장소입니다.

## 저장소 범위

이 저장소는 의도적으로 다음 파일만 관리합니다.

- `Assets/Scripts` 아래의 C# 스크립트
- 스크립트 GUID를 유지하는 데 필요한 관련 `.meta` 파일
- 저장소 사용 방법을 설명하는 문서와 Git 설정

씬, 프리팹, ScriptableObject 데이터, 이미지, 오디오, 애니메이션,
`Packages`, `ProjectSettings` 등은 로컬 Unity 프로젝트 또는 별도의 저장
수단에서 관리하며 이 저장소에는 포함하지 않습니다. 따라서 이 저장소만
복제해서는 완전한 Unity 프로젝트를 복원하거나 실행할 수 없습니다.

## 사용 방법

1. 별도로 준비된 Unity 프로젝트를 엽니다.
2. 이 저장소의 `Assets/Scripts`를 프로젝트의 동일한 경로에 배치합니다.
3. `.meta` 파일을 함께 유지해 기존 씬과 프리팹의 스크립트 참조 GUID가
   변경되지 않도록 합니다.
4. 씬과 에셋을 포함한 전체 프로젝트 백업은 이 저장소와 별도로
   관리합니다.

Unity가 생성하는 `Library`, `Temp`, IDE 프로젝트 파일과 로컬 에셋은 Git
관리 대상이 아닙니다. 로컬에서 생성된 `.csproj`를 이용한 빌드는 코드
검증 용도이며, 새로 복제한 이 저장소 단독으로 실행되는 빌드는 아닙니다.

## 개발 환경

- Unity 6
- C#
- Visual Studio Code

## 현재 던전 규칙

- 한 번의 런은 무작위로 정한 5~8회의 전투와 전투 사이의 강화 이벤트로
  구성됩니다.
- 런을 시작할 때 모든 전투의 난이도 스케일과 적 구성 시드를 미리
  결정합니다. 첫 전투는 스케일 0, 최종 전투는 스케일 100으로 고정하고,
  중간 전투는 진행도에 무작위 보정을 더하되 이전 전투보다 높아집니다.
- 스케일 0은 `Basic Turret` 1기가 제한시간 동안 낼 수 있는 이론 피해량의
  93%를 적 전체 체력으로 배분합니다. 기본 설정은 적 16기이며, 타겟 교체와
  실제 조작 시간을 고려해 간신히 클리어할 수준을 목표로 합니다. 현재
  기준에서는 총 체력 112를 유지하면서 각 적의 체력을 5~9 사이로 무작위
  분배합니다.
- 플레이어는 `Basic Turret` 1기로 시작하며 터렛은 최대 4기까지 보유할 수
  있습니다.
- 이벤트에서는 보유한 각 터렛의 적용 가능한 강화와 중복 획득 가능한
  신규 터렛, 에너지 강화, 소모형 아이템 전체를 하나의 후보 풀로 구성하고,
  그중 무작위로 제시되는 3개 보상 중 하나를 선택합니다. 구성 비율은
  제한하지 않으므로 같은 종류의 보상만 3개 등장하거나 특정 종류가 하나도
  등장하지 않을 수 있습니다. 보유 한도에 도달한 뒤 획득한 터렛은 기존
  슬롯 하나와 교체되며 이전 강화 상태를 계승하지 않습니다.
- 에너지는 전투 시작 시 최대치로 충전되며 기본 최대치는 3입니다. 적 처치
  보상 대신 전투 시간 5초마다 1씩 회복합니다. 이벤트에서 최대 에너지
  `+1` 또는 회복시간 `-0.5초`를 선택할 수 있으며 회복시간의 최솟값은
  0.5초입니다.
- 새 던전 런은 `화염병`, `지정 사격`, `과잉 보급`, `과열` 중 하나를 무작위로
  1개 지급합니다. 왼쪽 아이템 패의 `집중`은 기본 재사용 카드로, 대상 적을 5초 동안 모든
  터렛의 최우선 대상으로 지정하고 10초의 재사용 대기시간을 가집니다.
  화염병, 지정 사격, 과잉 보급, 과열은 이벤트에서 획득하며 사용 성공 시
  한 장을 소비합니다. 같은 소모품은 중복 획득해 수량으로 보유할 수
  있습니다.
- 화염병은 적 한 기에 3초 동안 1초 간격의 화염 피해를 부여하고, 지정
  사격은 적 한 기에 피해 5를 줍니다. 과잉 보급은 선택한 터렛의 실제 공격
  주기를 5초 동안 2배 빠르게 하며, 과열은 3초 동안 일반 공격력을 2배로
  만듭니다. 화염 타워의 과열은 공격력 대신 화염 지속시간을 2배로 만듭니다.
- 공격이 발동한 타일은 붉은색으로 0.5초 동안 표시합니다. 같은 시간에
  공격 범위가 겹치면 알파값을 1회 100, 2회 150, 3회 200, 4회 이상
  250으로 높여 중첩 범위를 구분합니다.
- 터렛에 마우스를 올리면 현재 강화 상태가 반영된 기술 코스트, 피해량,
  대상 수와 지속시간을 툴팁으로 표시합니다.
- 최종 전투 승리 시 던전을 클리어하고, 패배 시 런 진행도와 터렛 구성을
  초기화합니다.
- 파이어 터렛의 공격력 강화는 화상 지속시간을 1초 늘리고, 기술 공격력
  강화는 범위 중심 대상을 1기 늘립니다. 겹친 범위의 화상 지속시간은
  합산됩니다.

시작 BGM은 현재 `AudioManager`의 `Audio Test` 클립을 사용하는 프로토타입
설정입니다.
